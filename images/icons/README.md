# Research theme icons

Drop a small square icon here for each research theme and it will appear
automatically on the homepage theme cards (until then, a dashed placeholder
tile in the theme color is shown).

- Filename must match the theme slug: `images/icons/<slug>.svg`
- Recommended: simple SVG (or PNG), roughly 40×40, single/few colors.

Expected files:

- `sparsity.svg`
- `cortical-theory.svg`
- `continual-learning.svg`
- `anomaly-detection.svg`
- `vision-attention.svg`
- `neural-net-foundations.svg`
